🔊 Block THUD! — Test des sons

Chaque bouton joue le fichier réel du jeu avec le même volume qu'en partie. Ta décision : « garde / trop fort / trop faible / pas le bon mood » par son.

Ces 13 sons sont embarqués dans l'AAB. Les booms de bombe, les voix (Great! Amazing!…) et les sons par style de bloc (gel, bonbon, diamant…) restent synthétisés par le moteur : ils se testent en partie. — boom.mp3, voice_*.mp3, clear_*.mp3 sont les emplacements libres pour plus tard.
