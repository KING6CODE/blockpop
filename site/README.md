# Site Block THUD! (GitHub Pages)

À publier sur **king6code.github.io** (repo `king6code/king6code.github.io`,
branche main, racine) :

1. Créer le repo public `king6code.github.io`
2. Copier `app-ads.txt` et `privacy.html` à la racine
3. Attendre ~5 min → vérifier :
   - https://king6code.github.io/app-ads.txt
   - https://king6code.github.io/privacy.html
4. Dans la Play Console : URL politique de confidentialité =
   https://king6code.github.io/privacy.html

`app-ads.txt` autorise officiellement AdMob à vendre l'inventaire de
l'app (ID éditeur pub-8086962907043995) — sans lui, une partie des
acheteurs n'enchérit pas.
